# DevRoast

DevRoast é uma plataforma para desenvolvedores compartilharem snippets de código e receberem feedback construtivo da comunidade.

## Funcionalidades

- **Compartilhamento de Código**: Cole seu código e receba uma análise instantânea.
- **Sistema de Roast**: Um sistema de pontuação baseado na qualidade do código (ou na falta dela!).
- **Leaderboard**: Veja os "piores" códigos do mês e tente não aparecer lá.
- **Análise de Diffs**: Visualize alterações de código de forma clara.

## Sobre o Projeto

Este aplicativo foi construído durante o evento **NLW da Rocketseat**, na trilha de fullstack.

## Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Acesse http://localhost:3000 no seu navegador.
